# 使うツール・素材サイトのカタログ(積極的に使う)

オーナーが設計で使いたいツール・サイト。**積極的に使い、素材は「作る前にまず探す」**。ただし、使う前に商用利用の条件を必ず確認する。
最終確認日: 2026-11-06。条件は変わる。**使う時点で公式のページを確認**し、確認した日・URL・条件を `docs/asset_list.md` に記録する。

## 使う前の確認(必須)
- [ ] 商用利用が可能か(広告・課金ありのアプリを含む)
- [ ] クレジット表記の要否(必要なら、設定画面の「ライセンス」に載せる)
- [ ] 素材ファイルそのものの再配布・再販売の禁止(アプリに組み込んで配布するのは可、の形かどうか)
- [ ] 学習・生成物の権利(AI ツールの出力)、ログイン・アカウントの要否
- [ ] 確認できなかったものは使わない。「未確認」のまま本番に入れない。
- 凡例: ◎=今回、一次/二次情報で確認した / ○=一覧の記載のみ(公式未確認) / △=確認できなかった・食い違いがある

## 同型のリスク(4.3 対策)
CC0 の素材パックは、多くの人が使う。**同じパックだけで構成すると、他アプリと同じ見た目になり、「同型・テンプレート」と見られやすい。**
- 素材は、色・組み合わせ・加工で、自分のアプリの世界観(系統・Era・Voice)に合わせる。1つのパックに頼りすぎない。
- アイコンと起動アニメーションは、素材パックを使わず新しく作る(`modes/asset_requests.md`)。
- 他の自分のアプリと、同じ素材の組み合わせを使い回さない。

## 使い方(フォーマット内での位置づけ)
- 企画(段階0〜1b): Google Trends で需要を確認。素材は「作る前に探す」。
- 実装: AI 機能は、核の価値に効き、フォールバックを作れる時に Foundation Models。ゲームの素材は B 群を第一候補に、世界観に合わせて加工する。
- 素材の依頼(`modes/asset_requests.md`): まずこのカタログで探し、合うものがあれば使う。なければ ChatGPT などで作る。
- リリース後: Analytics、Search Console で確認し、結果を `ExperiencePoints.md` の候補にする(申請完了後)。
- 使ったツール・素材は、出典・ライセンス・確認日を `docs/asset_list.md` に残す。
