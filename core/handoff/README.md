# 渡し方の指示文(コピペ用)

アプリのリポジトリで Claude Code を開き、状態に合う文を貼る。`〔〕` はオーナーが埋める。
手順の共通部分: 先に `setup.sh` でフォーマットを取り込む(既存ファイルは上書きされない)。

```bash
cd /path/to/dev_format
./setup.sh /path/to/app-repo --store apple --engine swiftui   # google-play / godot / android も可
```
既にアプリ側に `CLAUDE.md` がある場合は上書きされない(部品を手動で追記する)。コピー後は、アプリ側のリポジトリでコミットする(個人情報・鍵は pre-commit が止める)。

## A. 新規(これから作る)
```
このリポジトリに開発フォーマットを取り込み済みです。CLAUDE.md を読んで従ってください。
アプリは新規です。
- 詳細設計書: docs/design_brief.md / 参考画像: docs/references/
- ストア: 〔Apple / Google Play〕 エンジン: 〔SwiftUI / Godot / Android〕
設計書は出発点で、そのとおりでなくて構いません。
段階0(core/review_prompts/0_brief_intake.md)から始めてください:
ダイス → Era / Rule / Voice の3つの質問 → アイコン用プロンプト → 画面の参考画像の確認、の順です。
会話は、おすすめ3つ+自由指示の4択で進めてください。
実装が終わるまで Archive・アップロードはしないでください。
```

## B. 実装中(途中まで作ってある。未申請)
```
このリポジトリに開発フォーマットを取り込み済みです。CLAUDE.md を読んで従ってください。
アプリは実装中で、未申請です。
core/review_prompts/existing_app.md の手順で進めてください。
- ダイスは振りません(振るのは、私が「設計を作り直したい」と言った時だけ)。
- 守りたいもの(変更不可): 〔機能・デザイン・名前など〕
- まず現状を読み、診断(重大 / 推奨 / 提案)を短く見せ、その後に私へ質問してください(番号で答えられる形で)。
- 審査への返信文・Apple の質問への回答案は作らないでください(未申請のため)。
会話は4択で進めてください。
```

## C. 実装完了・未申請(提出前)
```
このリポジトリに開発フォーマットを取り込み済みです。CLAUDE.md を読んで従ってください。
アプリは実装が完了しています。まだ申請していません。
existing_app.md の②の手順で、提出前のチェック(2_development → 2b_edge_cases → 3_submission、Codex 用のレビュー指示)を行ってください。
重大な問題が残っていなければ、申請用のコピペリスト(申請キット)を作ってください。個人情報は書かず、私が手入力します。
Web ページ(サポート・プライバシー・テスト案内)も、申請と同時に用意してください。
```

## D. 申請済み(審査待ち・リジェクト後・公開済み)
```
このリポジトリに開発フォーマットを取り込み済みです。CLAUDE.md を読んで従ってください。
アプリの状態: 〔審査待ち / リジェクト後 / 公開済み(アップデート)〕
existing_app.md の手順(③④⑤のうち該当するもの)で進めてください。
- リジェクトの場合: Apple のメッセージ全文を、この下に貼ります。〔貼り付け〕
  → 聞かれている項目だけに答えてください。返信文は、貼ったメッセージがある時だけ作ってください。
- 審査待ち・公開済みの場合: 申告(プライバシー・年齢制限・課金)と実装の食い違いを確認してください。
- 診断結果の後に、目的・守りたいもの・変えてよい範囲・期限を、番号で質問してください。
問題が解決するまで対応を続けてください。
```

## 補足
- どの場合も、レビューと安全の基準は常に100%(ダイスに依存しない)。
- 申請後に更新できるのは `ExperiencePoints.md` だけ(オーナーの指示がある時を除く)。
- ChatGPT / Codex へのレビュー・画像の依頼文は、`review_prompts/external/` と `modes/asset_requests.md` で出してもらう。
