# 会話の形態(最初の質問)

新規でも既存アプリでも、**最初の返信で必ず1問だけ聞く**(新規は Q1〜Q3 と同じメッセージの末尾に Q4 として)。選択肢の文面は、そのまま使ってよい。

```
Q4 会話の形態は？(番号で。「おまかせ」なら 1)
 1. 推奨(これまで通り) … 約8割を、おすすめ3つ + 自由指示1つの選択肢で進める
 2. 基本会話 … 選択肢を出さず、普通の会話で進める
```

## 1. 推奨(既定)
- 質問・提案は、おすすめ3つ + 自由指示1つの4択で出す。オーナーは番号で答えればよい。
- 約8割がこの形。残りは、自由に書くほうが早い時(短い確認、報告など)。
- 選択肢は縛りではない。番号の羅列を貼られたら「その順に実行」の意味。

## 2. 基本会話
- 選択肢の形にしない。結論 → 必要なら質問を1〜2個、の通常の文章で進める。
- 質問は、答えが要るものだけ。まとめて聞く時は番号を付けてよい。
- 途中で「選択肢で」と言われたら、1 に切り替える(逆も同じ)。

## 共通
- 説明は最低限。入力を求める時と手順の指示だけ丁寧に。
- 審査・安全・個人情報・「変更不可」の扱いは、形態で変わらない。
- 答えを受けたら `docs/mode_log.md` に1行で記録し、確認の質問は重ねない。
