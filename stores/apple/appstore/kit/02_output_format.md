# 申請キット指示書: 出力形式(§6)

(入口: `appstore/submission_kit_instructions.md`)

## 6. 出力形式(画面順 + 1フィールド1ブロック)
出力先: `appstore/kit.md`(個人情報を含まない)。
タイトル: `[アプリ名] App Store Connect申請キット｜[初回/更新]｜v[バージョン]`
冒頭に「今回の入力順」「対象プラットフォーム」「Xcodeビルド形式」「申請可否」「本人操作の残件」を短く示す。
各入力欄に、次の書式を繰り返す。

```
【画面】アプリ → [対象アプリ] → iOS App → [バージョン]
【セクション】[Apple画面の正式表記]
【入力欄・タグ】[実際の欄名]
【扱い】今回入力/前回値を維持/設定済み・確認のみ/利用時のみ/対象外/入力保留
【操作】テキスト貼り付け/プルダウン選択/ラジオ選択/チェックを付ける/チェックを外す/スイッチON/OFF/ファイルをアップロード/表示確認
【根拠】プロジェクト実装/App Store Connect現設定/Apple公式資料/本人決定事項
【文字制限】上限と原稿の実測文字数
【貼り付け内容】
(この欄に貼る文字列のみをコードブロックで)
```

- 貼り付け用ブロックには、説明・見出し・注釈・引用記号・文字数・未確定のプレースホルダーを入れない。個人情報の欄は、貼り付けブロックを作らず「本人が手入力」と書く(電話番号だけ `+81 XXXXXXXXXX`)。URL、アプリ名、説明文、キーワードは別々のブロックにする。
- 選択式は回答ラベルを明記する。存在しない欄は対象外と理由を示す。ファイルは用途、保存場所、ピクセル寸法、形式、実在確認を明示する。
- 同じ値が複数画面に必要なら、画面ごとに再掲する(「前述と同じ」は禁止)。
- 言語ごとに独立して記載する。実画面の見出しと順序を優先する。
- 更新時は各欄に「変更/据え置き/新設/対象外」の区別を入れ、前回の説明との整合を示す。
