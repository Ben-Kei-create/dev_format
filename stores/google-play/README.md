# Google Play(未整備)

まだ、このフォーマットには Google Play 用のルールがない。最初に出す時に、次を調べて整備する。
- 審査・ポリシー(重複・スパム、広告、子ども向けなど)
- 申請に必要な情報(ストア掲載情報、データセーフティ、プライバシーポリシーなど)
- テスト要件(新規の個人アカウントに、公開前のテストの条件があるとされる。最新の条件は公式で確認)
- スクリーンショットの仕様、公開ページ(`web/`)との関係
- `appstore/` 相当の申請キットと、提出前チェック

整備するまで、`--store google-play` を指定した場合は、共通ルール(`core/`)だけが入る。
