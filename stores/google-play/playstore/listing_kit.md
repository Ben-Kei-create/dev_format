# Google Play 掲載情報の申請キット(コピペリスト)の作り方

**提出前チェック(`review_prompts/3_submission.md`)に通過してから作る。** 出力先: `playstore/kit.md`(個人情報を含まない)。
実装されていない機能は書かない。個人情報(姓名、メール、電話)は書かず、本人が Play Console に手入力する。
文字数などの制限は、Play Console の画面と公式ヘルプで確認する(下は確認時点 2026-11-06。公式の記載と書いてあるものは、Play Console ヘルプで確認済み)。

## 出力の形式(1フィールド1ブロック、画面順)
```
【画面】Play Console → アプリ → [アプリ名] → [メニュー]
【項目】[実際の欄名]
【扱い】今回入力 / 設定済み・確認のみ / 対象外 / 入力保留
【根拠】実装 / Play Console の現設定 / 公式資料 / 本人決定事項
【文字制限】上限と原稿の実測文字数
【貼り付け内容】
(この欄に貼る文字列のみ。説明・注釈・プレースホルダーを入れない)
```
個人情報の欄(連絡先メール、電話、事業者の名前・住所など)は、貼り付けブロックを作らず「本人が手入力」と書く。電話番号は `+81 XXXXXXXXXX` の形。

## メインの掲載情報
| 項目 | 目安・要件 | 確認 |
|---|---|---|
| アプリ名(タイトル) | **30文字以下**。ローカライズは言語ごとに1つ。全角・半角を同じ1文字として数える | 公式 |
| 短い説明 | 80文字以内。公開に必須 | 公式 |
| 詳しい説明 | **4,000文字以内** | 公式 |
| アプリアイコン | 512×512 px、32ビット PNG(アルファ付き)、1,024KB 以下 | 公式 |
| フィーチャーグラフィック | 公開に必須。1024×500 px とされる | 公式(必須)/ 二次(サイズ) |
| スクリーンショット | 最低2枚とされる。JPEG または24ビット PNG(アルファなし)。寸法・枚数の上限は公式で確認 | 二次 |
| 動画(任意) | 必要な時のみ | — |
- 説明文の最初の数行で価値が伝わるようにする。キーワードの詰め込み・繰り返し・無関係な語は違反(Store Listing and Promotion ポリシー)。
- 世界観(Voice mode)を、文面にも反映する。誇張・未実装の機能・他社ブランド名の使用は書かない。
- 言語ごとに独立して書く。画面の見出しと順序は、実際の Play Console を優先する。

## 連絡先・ポリシー
- プライバシーポリシーのURL(必須): `appstore/common.md` の規則に従う公開ページ(`web/`)。申請前に公開済みであること。
- 連絡先メール、電話、ウェブサイト: 本人が手入力。サイトは公開ページ。

## 更新(アップデート)時
前回値を維持できるものと、改めて申告するもの(データセーフティ、広告、ターゲット層、権限)を分け、変更に伴う再申告を確認する。
