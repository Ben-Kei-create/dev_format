# スクリーンショット(Google Play)

## 原則(Apple と同じ)
- **捏造しない。** 実際に動くアプリの画面だけ。
- **テスト広告を写さない。** 個人情報、デバッグ表示、ダミーの文字を写さない。
- 他アプリと酷似した構図・素材にしない。

## 撮り方
- Android Studio のエミュレータ、または実機。端末の画面比率・寸法の要件は、Play Console の画面と公式ヘルプで確認する(固定のサイズを決め打ちしない)。
- 撮影用の状態(サンプルデータ、広告を隠す撮影モード)を用意する。撮影モードは、出荷版に含めない。
- 時刻・電池表示を整える(エミュレータの設定で、きれいな表示にする)。
- 保存: `docs/screenshots/{端末種別}/01-home.png` のように連番。

## 構成(推奨)
1. 何のアプリで誰向けかが一目で分かる画面(1枚目が最重要)
2. 主要機能 3. 操作に対する画面の変化 4. 差別化の機能 5. 結果・進捗・設定 6. その他の実在の特徴

## 他の素材
- アイコン: 512×512 px、PNG。**アプリアイコンの図柄を、他の場面に使い回さない**(`modes/asset_requests.md`)。
- フィーチャーグラフィック(公開に必須): 世界観に合わせた1枚。ChatGPT で作る(指示は AI が出す)。文字は入れない、または最小限。コードで文字を載せる場合は固定フォント。

## 提出前チェック
- [ ] 寸法・形式・枚数が、Play Console の現在の要件に合う
- [ ] 全ての画面が実際の動作と一致している
- [ ] テスト広告、デバッグ表示、ダミー文字、個人情報が写っていない
- [ ] 説明文・キャプションの内容が、実装済みの機能だけである
- [ ] 他アプリと酷似していない
